## HOW TO DEPLOY (3 STEPS)

### 1. EXTRACT THIS ZIP
Unzip this folder to your desktop or a temp location.

### 2. COPY FILES INTO YOUR PROJECT

**Option A — Easy way (recommended):**
- Drag the `components` and `pages` folders from this zip directly into your `seco-bio-website` project folder
- It will ask "Replace?" — click YES for both files

**Option B — Manual:**
- Open `seco-bio-v2-complete/components/`
- Copy `HomePage.jsx` → paste into your `seco-bio-website/components/` (replace old one)
- Copy `PlatformSciencePage.jsx` → paste into your `seco-bio-website/components/` (new file)
- Open `seco-bio-v2-complete/pages/`
- Copy `index.jsx` → paste into your `seco-bio-website/pages/` (replace old one)

### 3. GITHUB DESKTOP + NETLIFY

1. Open GitHub Desktop
2. Your repo shows 3 files modified:
   - `components/HomePage.jsx`
   - `components/PlatformSciencePage.jsx` (added)
   - `pages/index.jsx`
3. **Commit message:** `"v2 complete: full restructure with Joe's copy, brand lockup, Platform & Science combined"`
4. **Push to origin**
5. **Netlify redeploys automatically** (2–3 minutes)
6. **Live at:** https://secobio.netlify.app/
